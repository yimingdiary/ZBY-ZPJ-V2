# 认证素材和标签修正

用户指出的原因：此前复制了录屏系统UI、选中字号变化与原版不符、标签不能手动拖动，以及认证文字字体不同。

本轮删除仿制状态栏所有DOM（不是只隐藏灵动岛），以浏览器safe-area替代固定系统区。栏目字号固定1rem=402点基准中的16px，仅字重与颜色变化。

认证文字原图为已有缓存提取文件 certification.png，1029×66，透明PNG，完整包含图标、抖音旗舰、分隔线、抖音商城官方认证、品牌旗舰。上一版拆成HTML后受字体排版影响，本版恢复使用该图。原素材字形可原样复用，但网页缩放、外层背景合成与动态数据并不能因此声称100%一致。

将用户提供608×96截图的认证条区域按页面宽度归一化，与独立页面认证条对照，使用同一提取素材调整显示尺寸，未修改素材像素。

口碑标签真实overflow-x:auto；CSS平移动画移除，分别处理鼠标拖动和原生触摸滚动，拖动期间抑制外层口碑按钮的误点击。评分与粉丝部分保持固定，符合已捕获Android层级右侧HorizontalScrollView结构。

验证：16px字号不变，字重400→600；触摸scrollLeft=129、鼠标scrollLeft=212；横向操作未打开弹窗且scrollY=0；原图自然宽高1029×66；没有动态岛/状态栏/录屏时间DOM，无脚本错误、失败资源与站外请求。本轮未操作抖音App。

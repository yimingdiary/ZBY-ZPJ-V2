# 原始实现来源与还原边界

## 已取得的实际文件

1. 安装包：MuMu 已安装的抖音 Android 41.1.0，原 APK 仅复制后离线分析，未修改安装包。
2. 原始 Slice 模板：APK 类 `X.C20010MLc` 的模板表列出品牌头部、精简头部等模板地址；本轮从这些无需登录的静态资源地址读取 JSON，保留来源和 SHA256。`shop_top_bar` 是同一模板表注册的类型，本轮在同一资源目录中验证地址返回 HTTP 200 后取得顶部导航模板。
3. 原生交互代码：从 `classes6.dex` 离线反编译出 TopSheetLayout、ECShopSliceProfilePresenter、ECShopSliceTopBarPresenter、ECShopBackgroundPresenterBrand 等相关类。本轮全 DEX 反编译有 55 处错误，不能视为恢复原工程；这里只使用已成功解出的相关方法，不使用未解出的方法作证据。
4. 当前页面层级：上一轮已复制的 ECStoreActivity 视图树，确认品牌内容区为 Lynx、头部使用 Slice 视图、并有 TopSheetLayout 原生滚动框架。
5. 系统字体：从 `/system/fonts` 只读复制 Roboto 和 NotoSansCJK-Regular，按系统 fonts.xml 的 zh-Hans 索引 2 取得中文字体，再仅保留当前页面需要的字形，输出为 WOFF2。哈希和字符数见 android-font-provenance.json。
6. 素材：原有图片缓存；从原模板静态地址取得的返回、分享、店标边框、关注按钮图标；APK 中 DouyinNumberABC 数字字体。

## 由真实文件确认的公式

- `profile_scroll_percent = scrollY / getTopSheetViewHeight()`，见 TopSheetLayout.java 的 LIZJ 方法。
- 大店标透明度：`1 - (p - 0.02) / (0.14 - 0.02)`。
- 店名和口碑透明度：`1 - (p - 0.19) / (0.5 - 0.19)`。
- 直播/会员模块和认证条透明度：`1 - (p - 0.19) / (0.76 - 0.19)`。
- 搜索样式分支中的顶部小店标透明度：`(p - 0.27) / (0.44 - 0.27)`。
- 顶部左侧占位宽度：`149 - 21 * clamp(p / 0.44, 0, 1)`；由此计算搜索框扩展位置，不再按估计的像素阈值切换。
- 品牌背景黑色遮罩渐变顶部 alpha：`51 + 102 * clamp(p,0,1)`，中部 ARGB `#C2000000`，底部 `#FF000000`，见 ECShopBackgroundPresenterBrand.java。

模板中的 `p` 是 profile_scroll_percent。输出到网页时必须限制透明度到 [0,1]。

## 这次网页的改法

`source-templates/` 保留下载的 JSON。

`scripts/compile-source-styles.py` 从这些 JSON 中读取对应元素的大小、文字参数、圆角、渐变和透明度表达式，生成 `dist/source-style.css`、`dist/source-contract.js`；原公式也保留在生成结果中。布局单位映射结合已导出的当前设备层级（480dp 页面宽度与 375 设计单位）核对。定制的 ECShopScrollText 与普通 Slice Text 对字体尺寸的处理分开适配，不能把所有单位都当作同一套 CSS px。

网页还是 DOM/CSS 的独立适配层，**没有运行原版 Android Slice 或 Lynx 引擎**，没有把整个 App 的业务逻辑直接搬到网页。因此「使用原始参数」不等于「已完成 100% 原版运行结果」。

## 已证实的限制

本轮使用普通 ADB shell（uid=2000）只读检查，抖音私有 files/cache 目录明确返回 Permission denied。没有使用 su/root、run-as 绕过、注入、重签或抓包证书。

因此还缺少：

- 该页面实际加载的模板版本/哈希，无法证明 CDN 当前文件和录屏时缓存版本相同。
- 当前店铺的完整服务端样式数据，包括模板中动态绑定的颜色、宽高、文本样式和设置开关。
- 当前品牌内容区的完整 Lynx 模板和运行数据。
- 所有原生控件的完整运行环境、安卓排版/测量与手势惯性行为。
- 原版服务端行为：关注、领券、直播播放、搜索和购买等。独立预览仍然只模拟这些动作，不向抖音发送请求。

网页内部分尚未取得来源的内容区/弹层仍属于上版演示，不应声称它们是抓取到的原始界面。可确定的原始参数已替换，不以估算值冒充提取结果。

## 账号边界

本轮没有点击、滚动或刷新抖音，没有读取账号凭证；网络读取只访问无需登录的静态模板/图标资源，不附带抖音 cookie。只读权限检查和系统字体复制不会产生关注、领券或交易行为，但不能对平台规则作零风险保证。

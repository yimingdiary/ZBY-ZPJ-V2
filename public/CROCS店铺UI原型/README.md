# CROCS 店铺头部：原始参数适配版

本轮从「按画面估算」改为优先使用已提取的实际模板和代码。重点是店铺头部的样式与折叠交互。

## 原始来源

- `source-templates/shop_profile_brand.json`：原版品牌头部 Slice JSON。
- `source-templates/shop_top_bar.json`：原版顶部导航 Slice JSON。
- `source-templates/shop_profile_brand_concise.json`：另一精简头部模板，仅保留作来源研究。
- `source-evidence/`：相关 APK 反编译代码、模板来源、字体来源、哈希、边界说明。
- 背景、字标、认证条、店标图标、会员图标等使用实际提取素材；顶部图标采用原模板的静态资源。
- 数字字体来自 APK；中文和拉丁字体来自模拟器系统的实际字体文件（已按当前页面文字压缩为 WOFF2）。

## 参数生成

运行 `python3 scripts/compile-source-styles.py`。

它读取实际模板，生成 `dist/source-style.css` 和 `dist/source-contract.js`。店标/店名/卡片/认证条淡出、小店标淡入均使用原始表达式；滚动进度按原生 TopSheetLayout 的公式计算。

原版头部背景保留在屏幕上，内容向上滚动并按模板公式淡出；搜索框按顶部模板展开；取消了上一版没有来源支持的白色导航栏。

## 使用

打开 `dist/index.html`，或运行 `python3 -m http.server 8765 --directory dist` 后浏览 http://127.0.0.1:8765。

## 重要边界

这仍然是独立网页适配，**没有直接运行原生 Slice/Lynx 渲染引擎，不能声称已达到100%一致**。私有模板缓存没有读取权限，尚未匹配录屏页面的实际模板版本、服务端样式配置和完整品牌内容模板。可核实的原始参数已替换，未取得原始实现的弹层、列表、商品数据和业务动作仍为演示。商品价格/销量为演示数据。

完整说明见 `source-evidence/来源与还原边界.md`。

## 账号隔离与验证

网页全部使用本地静态资源，不接入抖音 API、登录信息、cookie 或 token；关注、入会、直播和购物袋只在预览内演示。CSP 限制站外请求。本轮未点击、滑动、刷新抖音，未提权、注入、重签、安装证书或修改应用。

Chrome 在 584px/390px 视口验证展开、过渡、折叠、背景位置、标签吸顶、搜索框伸展、会员弹层和轮播手势。无页面脚本错误、站外网络请求或横向溢出；横向轮播不再误触打开商品栏。

以用户提供的 `ScreenRecording_11-17-2026 15-21-16_1.MP4` 为当前视觉和交互参考，替代此前 Android 页面比例。新增 `dist/ios-refinement.css` 和 `dist/ios-interactions.js`：

- 点击任意栏目，包括已选中的品牌，均收起头部并吸顶；栏目内容水平过渡，支持在内容区横向滑动。

- 认证条图标、文字、分隔线分开排版并垂直对齐；关注按钮渐变、尺寸、领券角标、按压动画和关注/取消关注本地状态。

验证使用 Chrome 移动触摸模式（402×874、390×844）：自动收起/展开、点击栏目吸顶、下划线中途位置、横向栏目切换、连续关注/取消关注、资源与脚本检查。真实触摸协议事件上滑后 scrollY=214（收起位置214）、下拉后回到0；关注四次切换均保持scrollY=0。
